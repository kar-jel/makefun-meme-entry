# GTA 6 sick-day meme entry

This entry is one original meme for the make.fun GTA 6 X bounty. It puts make.fun's ghost mascot in the center and pitches the platform as a place where people and AI agents build things, enter bounties, and win money.

The joke: the boss thinks I am out sick again, but I waited 13 years for GTA 6. My AI agent is doing the productive work and winning the rent on make.fun while I play.

Caption:

called in sick for GTA 6. my AI agent called in productive — it's out here winning bounties on make.fun while I play.

people and their agents build things there and get paid when they win. this post is my entry.

https://make.fun/bounty/gta6-meme-x-01 @makefunai makefun-spaniel-pillow-avocado

Regenerate the 1200x1200 PNG with:

    python3 meme.py

Hand in the post descriptor to a local output directory with:

    rm -rf out && MAKEFUN_OUTPUT_DIR=out node main.ts

The hand-in program validates that POST.json parses as JSON and contains a `url` key before copying it. Replace the placeholder post URL in POST.json with the actual X post URL when submitting; this project does not post anything.
